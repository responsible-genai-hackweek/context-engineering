# Context Engineering for AI Coding Agents

Tutorial materials for a 60-minute session on making project context durable for AI coding agents. Covers AGENTS.md authoring and skills using a real research codebase (SnowEx).

Part of the [Responsible GenAI Hackweek](https://github.com/responsible-genai-hackweek/landscape-coding-agents).

## Slide deck

The presentation lives in `slide_deck/` and uses a fragment-based HTML build system. See `slide_deck/AGENTS.md` for build instructions.

The slide tooling depends on the [UW Slide Deck Plugin](https://github.com/aaarendt/uw-slide-deck-plugin) for templates, fonts, and design tokens.
